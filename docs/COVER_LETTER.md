# Сопроводительное письмо — шаблон

Составлено по резюме `CV_Алексей_Барсуков_2.docx`. `{company}` и `{vacancy}` подставляются
автоматически, когда появятся автоотклики (после одобрения приложения на dev.hh.ru). Пока можно
копировать вручную.

## Основной вариант

```
Здравствуйте!

Меня заинтересовала вакансия «{vacancy}» в {company}. Я frontend-разработчик с коммерческим
опытом с 2021 года, основной стек — React, TypeScript, Redux Toolkit, также работал с React Native.

Что могу принести команде:
— запуск продуктов с нуля: выбор стека, настройка проекта, проектирование frontend-архитектуры
  и ролевой модели (платформа Egile, «Защибиз», Домконнект.рф);
— разработку ключевых экранов, авторизации и переиспользуемых UI-компонентов (MUI, Ant Design,
  Styled Components), адаптив под разные устройства;
— unit-тесты на Jest и React Testing Library;
— работу с заказчиком и командой: уточнение требований, планирование задач, менторство.

Буду рад обсудить задачи и показать примеры работы. Удобно связаться в Telegram:
@Aleksey_Barsukov_development.

С уважением,
Алексей Барсуков
```

## Короткий вариант

Для вакансий, где письмо необязательно, или для быстрого отклика:

```
Здравствуйте! Откликаюсь на вакансию «{vacancy}». Frontend-разработчик с 2021 года:
React, TypeScript, Redux Toolkit, React Native. Запускал продукты с нуля, проектировал
архитектуру, писал тесты (Jest, RTL), менторил разработчика. Буду рад пообщаться —
```

## Советы

- Если в вакансии просят ответить на вопрос или указать что-то в письме (например, «напишите,
  почему вам интересен наш продукт»), добавьте ответ первой строкой — такие письма читают
  внимательнее, а письма без ответа часто отсеивают сразу.
- Для вакансий на Vue или Angular стоит добавить фразу о готовности быстро перейти на их стек:
  опыт React хорошо переносится.
- Для офиса или гибрида в Казани можно указать, что вы в Казани и готовы выйти быстро.
